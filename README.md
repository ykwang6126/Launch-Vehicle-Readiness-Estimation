# LVReadiness — Launch Vehicle Readiness Estimation

Research software for probabilistic readiness and mission-success assessment under limited test evidence. LVReadiness converts technical and organizational readiness scores into component Beta priors, pools multiple raters, propagates a seven-component fault tree, and updates system-level risk using test evidence.

## Status

Version 0.1 is under active review. The original uploaded package is currently under `lv-readiness/` on `main`. The working review branch, `review/readability-audit`, moves the package to the repository root and includes readability improvements that will be merged after review.

The public example is synthetic. Historical or restricted assessment data are not included in this repository.
