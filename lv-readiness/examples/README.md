# Examples

Start with [synthetic_demo](synthetic_demo/README.md). Its fictional workbook
covers all seven components using one rater and score 2 in both categories.
No real assessment responses are distributed.

After installing the package, run from the package folder:

```bash
python -m lvreadiness run examples/synthetic_demo/Inputs_sheet.xlsx --output outputs --seed 1
```

Use your environment's Python executable. See [the main README](../README.md)
for Windows/macOS setup commands.
